Prime Map API 1.0 — Referans

Herhangi bir X-Plane 11 eklentisine gömülebilen harita kütüphanesi · 2026-11-10

1. Tanım

Prime Map API, X-Plane 11 eklentilerinin kendi arayüzlerine katmanlı bir hareketli harita yerleştirmesini sağlayan bir C++ kütüphanesidir (SHARED DLL: prime_map.dll). Harita, verisini sadece X-Plane'den alır: kurulu DSF sahneleri (zemin, su, yollar), apt.dat (havalimanları), nav veritabanı, earth_awy.dat (hava yolları), dataref'ler (uçak) ve FMS (rota). Harita kendi XPLM penceresinde, kendi flight loop'uyla çizilir; host eklenti pencereyi açar, konumlandırır ve bütün davranışı API fonksiyonlarıyla yönetir. Haritanın yerleşik arayüzü (araç şeridi, katman paneli, mod paneli, çizim paleti, havalimanı arama, durum şeridi, tooltip) isteğe bağlıdır.

2. Hızlı başlangıç

Var olan bir X-Plane 11 eklentisine harita eklemek beş adımdır. Fonksiyonların tam listesi bölüm 5'tedir.

Adım 1 — Kütüphane reposunu edinin

prime_map_api reposunu eklenti projesinin yanına alın (kardeş klasör). İçeriği: genel başlık (PrimeMap.h, primemapglobal.h), CMake kütüphane tanımı, örnek eklenti (examples/map_api_test), bu belge. Sürüm notları CHANGELOG.md'dedir. SDK paketi üretilmez; tüketim CMake hedefi üzerinden yapılır (Adım 2).

Adım 2 — Derlemeye bağlayın

Gereksinimler: C++20, MSVC 2022 (/MD CRT — kütüphane ile aynı olmak zorunda), X-Plane SDK 3.0. X-Plane SDK'sı developer.x-plane.com/sdk adresinden indirilir (geliştirme ortamına göre C:\workspace\cots\X-Plane-SDK altına kurulur; repoda tutulmaz). Kütüphane aynı CMake oturumuna katılır ve hedef adına bağlanır:

add_subdirectory(${CMAKE_SOURCE_DIR}/../prime_map_api prime_map_build)
target_link_libraries(host PRIVATE prime_map          # include yolu transitif gelir
                      ${XPSDK}/Libraries/Win/XPLM_64.lib opengl32)
target_compile_definitions(host PRIVATE
    XPLM200=1 XPLM210=1 XPLM300=1 XPLM301=1   # SDK 3.0 seviyesi
    IBM=1 APL=0 LIN=0                          # Windows; APL/LIN diger platformlar

Host kodunda başlık: #include <prime_map_api/PrimeMap.h>. Derleme sonrası prime_map.dll, host eklentinin (win.xpl) yanına kopyalanmalıdır; DLL'i yükleyen host'un kendisidir.

Adım 3 — Yaşam döngüsünü bağlayın

Kütüphane XPluginEnable'da başlatılır ve harita açılır; XPluginDisable'da kapatılır. En küçük çalışan iskelet:

#include <prime_map_api/PrimeMap.h>

static std::unique_ptr<PrimeMap::Map> gMap;

PLUGIN_API int XPluginEnable(void)
{
    PrimeMap::InitConfig tInit;
    // mCacheDirectory bos birakilirse: <eklenti klasoru>/cache/
    if (!PrimeMap::Init(tInit))
        return 0;

    PrimeMap::OpenConfig tOpen;
    tOpen.mGeometry = { 100, 800, 640, 480 };   // sol, ust, genislik, yukseklik (boxel)
    tOpen.mUiVisible = true;                    // yerlesik arayuz (araç seridi, katman paneli ...)
    tOpen.mMouseInput = true;                   // fare ile kaydirma ve zoom
    gMap = PrimeMap::MapFactory::CreateMap(tOpen);   // veya: Map::Open(tOpen)
    return 1;
}

PLUGIN_API void XPluginDisable(void)
{
    gMap.reset();            // pencere kapanir
    PrimeMap::Shutdown();    // arka plan isleri durur
}

Veri yüklemesi arka planda sürer; harita hemen açılabilir, katmanlar veri geldikçe tamamlanır (bkz. bölüm 4). Kütüphane ayar/çizim dosyası yazmaz: pencere yeri, mod, katman görünürlükleri ve kullanıcı çizimleri bellekte tutulur; kaydetmek host'un görevidir. Kütüphane bunun için ExportSettings()/ImportSettings(), ExportDrawings()/ImportDrawings() metin fonksiyonlarını ve her değişiklikte artan GetSettingsRevision()/GetDrawingsRevision() sayaçlarını verir (bölüm 6, "Ayarlar" ve "Kullanıcı çizimleri"); host uygun anda dosyaya yazar ve açılışta geri yükler.

Adım 4 — Pencereyi host arayüzüne yerleştirin

Embedded stilde harita çerçevesiz çizilir; konumunu ve boyutunu host belirler. Host penceresi her taşındığında/boyutlandığında map->SetGeometry(...) çağrılır (koordinat kuralı: bölüm 4). Düğme/klavye bağlamak isteyen host PanLeft/Right/Up/Down, ZoomIn/ZoomOut, SetMode, SetLayerVisible gibi fonksiyonları kendi kontrollerine bağlar.

Adım 5 — Doğrulayın

Harita penceresi görünür ve durum şeridi veri yüklemesini gösterir. Başarısızlıkta işlemler sessizce yapılmaz; neden Log.txt'ye mLogPrefix ile yazılır (InitConfig::mLogCallback ile log'ları kendi dosyanıza da alabilirsiniz). Yükleme durumu için PrimeMap::GetStatus(), sürüm uyumu için PrimeMap::VersionString() kullanın. Yeni bir SDK sürümünde kütüphane reposunu güncellemeniz yeterlidir; API uyumsuzluğu major sürüm artışıyla bildirilir.

Veri yüklenirken harita hemen açılabilir; hazır olmayan katmanlar boş/kaba çizilir ve veri geldikçe tamamlanır (GetStatus). 9. Örnek: examples/map_api_test

Bütün API fonksiyonlarını çağıran ayrı bir X-Plane eklenti projesi; sadece paketi kullanır.

DosyaGörev
MapApiCalls.h/.cppHer API çağrısı ayrı bir metot (OpenMap, CloseMap, ZoomIn, SetLayerVisible ...). Eklentinin geri kalanı haritaya sadece bu sınıfla erişir
SelfTest.h/.cppX-Plane içinde bütün fonksiyonları sırayla çağırır, her kontrolü Log.txt'ye [map-api-test] PASS|FAIL olarak yazar
TestPluginMain.cppGiriş noktaları; Plugins > Map API Test menüsü aynı metotları elle çağırır (zoom, pan, mod, KSEA, katman, UI, fare, taşıma, boyut, göster/gizle)
#include "PrimeMap.h"

bool MapApiCalls::OpenMap(const PrimeMap::Geometry& pGeometry, PrimeMap::WindowStyle pStyle, bool pUi, bool pMouse)
{
    PrimeMap::OpenConfig tConfig;
    tConfig.mGeometry = pGeometry;
    tConfig.mStyle = pStyle;
    tConfig.mUiVisible = pUi;
    tConfig.mMouseInput = pMouse;
    mMap = PrimeMap::Map::Open(tConfig);
    return mMap != nullptr;
}
