1. Tanım ve ne sunar

Prime XMap API, bir X-Plane 11 eklentisinin (host) kendi arayüzüne katmanlı, hareketli bir harita koymasını sağlayan C++ kütüphanesidir (prime_map.dll). Harita verisini sadece o bilgisayardaki X-Plane kurulumundan alır: DSF sahneleri (zemin, su, kabartma, yollar), apt.dat (havalimanları), nav veritabanı, earth_awy.dat (hava yolları), dataref'ler (uçak) ve FMS (rota). Dış servis, internet ya da ek veri yoktur; simülatörde ne kuruluysa haritada o görünür.

ÖzellikDeğer
PlatformX-Plane 11 (11.50+), Windows x64, X-Plane SDK 3.0 (XPLM301). Host her zaman bir X-Plane eklentisidir.
Dil / derleyiciC++20, MSVC 2022, CRT /MD (host da /MD ile derlenmek zorunda)
Başlık / ad alanı#include <prime_map_api/PrimeMap.h> · namespace prime

Giriş noktasıprime::XMapManagerFactory::createXMapManager() → XMapManager → addXMap() → XMap
Görüntüleme yoluTexture: harita host'un istediği yere basılan bir openGL dokusu (framebuffer). API'nin hedef ve tek önerilen yoludur. Standalone ve Embedded pencere stilleri LEGACY'dir (bölüm 4.3): kodları korunur, yeni host kodunda kullanılmaz.
Harita sayısıSınırsız; her harita tamamen bağımsız (görünüm, mod, katmanlar, renkler, çizimler, zemin ayarları, dosyalar). Veri ve önbellek bir yöneticinin haritaları arasında ortak.
ThreadBütün fonksiyonlar X-Plane ana thread'inden çağrılır. Veri yükleme ve zemin üretimi kütüphanenin kendi arka plan thread'lerindedir.
Hata modeliİstisna yok. Geçersiz değer: işlem yapılmaz, Log.txt'ye tek satır WARNING, dönüş false / boş / varsayılan.

Özetle API ile yapabilecekleriniz (ayrıntı ve sınırlar bölüm 9'da): haritayı istediğiniz yere ve boyuta koymak; birden çok bağımsız harita; 5 harita modu (Scenery, VFR, IFR Low, IFR High, Dark); 56 katman / alt katmanın her birini mod başına açıp kapamak; katmanlara zoom aralığı vermek; 14 katmanın rengini değiştirmek; zeminin bütün renklerini, kabartmasını, suyunu, VFR yükseklik bantlarını ayarlamak; uçak ve rotayı X-Plane'den ya da host'tan almak; çizim (nokta / rota / bölge) eklemek, okumak, kaydetmek; ekran ↔ coğrafya dönüşümü ve imleç altındaki nesneyi sorgulamak; ayarları metin olarak dışa / içe aktarmak; zemin önbelleğini önceden hazırlamak.

2. Hızlı başlangıç (10 dakika)

Zaten derlenen bir X-Plane eklentiniz varsa haritayı kendi pencerenizin içine koymak için gereken her şey bu bölümdedir. Hiç eklentiniz yoksa bölüm 3'ten başlayın (tam, derlenen bir örnek proje verir).

2.1 CMake'e üç satır

add_subdirectory(${CMAKE_SOURCE_DIR}/../prime_map_api prime_map_build)   # kutuphane ayni oturumda derlenir
target_link_libraries(my_plugin PRIVATE prime-map-api)                    # include dizini ve /MD gelir
add_custom_command(TARGET my_plugin POST_BUILD                            # prime_map.dll win.xpl'nin yanina
    COMMAND ${CMAKE_COMMAND} -E copy_if_different $<TARGET_FILE:prime-map-api> $<TARGET_FILE_DIR:my_plugin>)

2.2 Açılış (XPluginEnable)

#include <prime_map_api/PrimeMap.h>

prime::XMapManager* gManager = prime::XMapManagerFactory::createXMapManager();
gManager->setDataDirectory(myPluginFolder);       // ayar + onbellek klasoru (bos: %LOCALAPPDATA%/prime/prime-xmap)
gManager->initialize();                           // nav / havalimani / zemin indeksi arka planda yuklenir

prime::XMapConfig tConfig;
tConfig.mName = "main";                           // ayarlar <veri>/maps/main/
tConfig.mStyle = prime::WindowStyle::Texture;     // pencere yok: harita bir dokuya cizilir
tConfig.mUiVisible = true;                        // haritanin kendi seritleri / panelleri
tConfig.mMouseInput = true;
prime::XMap* gMap = gManager->addXMap(tConfig);
gMap->setTextureSize(600, 400);                   // boxel
gMap->initialize();
gMap->setMode(prime::XMapMode::Vfr);              // istediginiz kadar ozellestirme (bolum 9)

2.3 Çizim (pencerenizin draw callback'i)

gMap->setTextureSize(mapWidth, mapHeight);        // pencere boyutlaninca; ayni boyutta is yapmaz
if (gMap->renderTexture())                        // gerekiyorsa yeniden cizer
{
    XPLMSetGraphicsState(0, 1, 0, 0, 0, 0, 0);
    XPLMBindTexture2d(static_cast<int>(gMap->getTextureId()), 0);
    // (mapLeft, mapBottom) - (mapLeft + mapWidth, mapBottom + mapHeight) dortgenine bas; doku (0,0) sol-alt
}

2.4 Girdi (click / cursor / wheel / key callback'leri)

gMap->injectMouse(x - mapLeft, y - mapBottom, prime::MouseAction::Down);   // Drag, Up; MouseButton::Right
gMap->injectMouseMove(x - mapLeft, y - mapBottom);                         // cursor callback: her karede
gMap->injectWheel(x - mapLeft, y - mapBottom, clicks);
if (gMap->wantsKeyboard()) { XPLMTakeKeyboardFocus(myWindow); }            // tuslar: injectKey(...)

2.5 Kapanış (XPluginDisable)

gManager->removeXMap(gMap);                        // ayarlar yazilir
gManager->shutdown();
prime::XMapManagerFactory::destroyXMapManager(gManager);

Kurulum: <X-Plane>/Resources/plugins/<eklentiniz>/64/ altında win.xpl ve prime_map.dll yan yana. Log.txt'de Prime Map API 0.26.0 ready satırını görün.

Adım 4 — Eklenti kaynağı (tamamı)

Bir X-Plane penceresi açar (taşınır, boyutlanır), haritayı içine doku olarak basar, fare / tekerlek / klavyeyi haritaya iletir ve haritayı özelleştirir. Bütün harita işi enable, customizeMap, draw, forwardClick ve callback'lerdedir.

// Prime XMap API'nin en kucuk tam ornegi: eklenti, haritayi WindowStyle::Texture ile kendi penceresine
// yerlestirir; girdileri inject* ile iletir, haritayi API ile ozellestirir.
// Akis:  XPluginEnable -> pencere + XMapManager + XMap (addXMap -> ayarlar -> initialize)
//        cizim callback -> setTextureSize + renderTexture + dokuyu dortgene bas
//        girdi callback -> doku koordinatina cevir -> inject*
//        XPluginDisable -> removeXMap -> shutdown -> destroyXMapManager -> pencere
#include <array>
#include <cstring>
#include <memory>
#include <string>

#include "XPLMDefs.h"
#include "XPLMDisplay.h"
#include "XPLMGraphics.h"
#include "XPLMPlugin.h"
#include "XPLMUtilities.h"

#include <GL/gl.h>

#include <prime_map_api/PrimeMap.h>

namespace
{

constexpr int kMargin = 8;  // pencere kenari ile harita arasi (boxel)

// Bu eklentinin klasoru: .../Resources/plugins/texture-host/ (sonunda ayirici ile)
std::string findPluginDirectory()
{
    std::array<char, 2048> tXplPath = {};  // SDK: en az 256 bayt
    XPLMGetPluginInfo(XPLMGetMyID(), nullptr, tXplPath.data(), nullptr, nullptr);
    std::string tPath = tXplPath.data();
    for (int tLevel = 0; tLevel < 2; ++tLevel)  // dosya adini ve "64" klasorunu at
    {
        const size_t tCut = tPath.find_last_of("/\\");
        if (tCut != std::string::npos)
        {
            tPath.erase(tCut);
        }
    }
    return tPath + XPLMGetDirectorySeparator();
}

class TextureHost
{
public:
    bool enable();
    void disable();

private:
    static void drawCallback(XPLMWindowID pWindow, void* pRefcon);
    static int clickCallback(XPLMWindowID pWindow, int pX, int pY, XPLMMouseStatus pStatus, void* pRefcon);
    static int rightClickCallback(XPLMWindowID pWindow, int pX, int pY, XPLMMouseStatus pStatus, void* pRefcon);
    static void keyCallback(XPLMWindowID pWindow, char pKey, XPLMKeyFlags pFlags, char pVirtualKey, void* pRefcon,
                            int pLosingFocus);
    static XPLMCursorStatus cursorCallback(XPLMWindowID pWindow, int pX, int pY, void* pRefcon);
    static int wheelCallback(XPLMWindowID pWindow, int pX, int pY, int pWheel, int pClicks, void* pRefcon);

    void customizeMap();                     // ozellestirme ornekleri
    void updateMapRect();                    // pencereden harita dikdortgeni
    void draw();
    int forwardClick(int pX, int pY, XPLMMouseStatus pStatus, prime::MouseButton pButton, bool* pPressed);
    void syncKeyboardFocus(bool pTake);

    XPLMWindowID mWindow = nullptr;
    prime::XMapManager* mManager = nullptr;  // sahibi biz: destroyXMapManager ile birakilir
    prime::XMap* mXMap = nullptr;            // sahibi mManager: removeXMap ile birakilir
    int mMapLeft = 0;                        // haritanin pencere icindeki yeri (global boxel)
    int mMapBottom = 0;
    int mMapWidth = 0;
    int mMapHeight = 0;
    bool mLeftPressed = false;               // basma haritada basladi: surukleme / birakma da haritaya
    bool mRightPressed = false;
};

bool TextureHost::enable()
{
    // 1) Host'un kendi penceresi: X-Plane cercevesi (tasinir, boyutlanir)
    XPLMCreateWindow_t tParams;
    std::memset(&tParams, 0, sizeof(tParams));
    tParams.structSize = sizeof(tParams);
    tParams.left = 100;
    tParams.top = 800;
    tParams.right = 900;
    tParams.bottom = 250;
    tParams.visible = 1;
    tParams.drawWindowFunc = drawCallback;  // SDK: butun callback'ler verilmeli
    tParams.handleMouseClickFunc = clickCallback;
    tParams.handleRightClickFunc = rightClickCallback;
    tParams.handleKeyFunc = keyCallback;
    tParams.handleCursorFunc = cursorCallback;
    tParams.handleMouseWheelFunc = wheelCallback;
    tParams.refcon = this;
    tParams.decorateAsFloatingWindow = xplm_WindowDecorationRoundRectangle;
    tParams.layer = xplm_WindowLayerFloatingWindows;
    mWindow = XPLMCreateWindowEx(&tParams);
    if (!mWindow)
    {
        return false;
    }
    XPLMSetWindowPositioningMode(mWindow, xplm_WindowPositionFree, -1);
    XPLMSetWindowResizingLimits(mWindow, 300, 200, 4000, 4000);
    XPLMSetWindowTitle(mWindow, const_cast<char*>("Texture Host"));

    // 2) Yonetici: ortak veri (nav, havalimanlari, zemin) ve onbellek. Veri klasoru bu eklentinin
    //    klasoru: baska bir host (ornegin resmi Prime XMap eklentisi) ile dosya / onbellek paylasilmaz.
    mManager = prime::XMapManagerFactory::createXMapManager();
    mManager->setLogPrefix("[texture-host]");
    mManager->setDataDirectory(findPluginDirectory());
    if (!mManager->initialize())
    {
        return false;
    }

    // 3) Harita: once nesne ve ayarlar, en son initialize. Texture: pencere acilmaz, dokuya cizilir.
    prime::XMapConfig tConfig;
    tConfig.mName = "main";                        // ayarlar <veri>/maps/main/
    tConfig.mStyle = prime::WindowStyle::Texture;
    tConfig.mMode = prime::XMapMode::Vfr;
    tConfig.mUiVisible = true;                     // haritanin kendi seritleri ve panelleri (dokunun icinde)
    tConfig.mMouseInput = true;                    // fare / tekerlek bizden inject* ile gelir
    mXMap = mManager->addXMap(tConfig);
    if (!mXMap)
    {
        return false;
    }
    updateMapRect();
    mXMap->setTextureSize(mMapWidth, mMapHeight);  // boxel; doku pikseli UI olcegine gore otomatik
    mXMap->initialize();                           // ayar dosyasi varsa burada okunur (LoadAndSave)
    customizeMap();                                // initialize'dan SONRA: her acilista koddaki deger gecerli
    return true;
}

void TextureHost::customizeMap()
{
    mXMap->setFollowAircraft(false);
    mXMap->setCenter(47.45, -122.30);              // KSEA
    mXMap->setZoom(10.0);
    mXMap->setZoomLimits(6.0, 15.0);               // bu harita 6'dan uzaga, 15'ten yakina gitmez

    // Katman gorunurlugu (bu mod icin; her modun durumu ayri saklanir)
    mXMap->setIsLayerVisible(prime::XMapLayer::Roads, false);
    mXMap->setIsLayerVisible(prime::XMapLayer::Fixes, true);

    // Zoom araligi: fix'ler ancak 10.5'ten yakinda; hava yollari 8'den yakinda
    mXMap->setLayerZoomRange(prime::XMapLayer::Fixes, 10.5, 99.0);
    mXMap->setLayerZoomRange(prime::XMapLayer::AirwaysGroup, 8.0, 99.0);

    // Renk: alcak hava yollari turuncu, VOR'lar kirmizi (renk verilebilen katmanlar: API belgesi bolum 9)
    mXMap->setColor(prime::XMapLayer::AirwaysLow, prime::Rgb{255, 140, 0});
    mXMap->setColor(prime::XMapLayer::Vor, prime::Rgb{220, 40, 40});

    // Zemin: daha guclu kabartma, VFR bant sinirlarinda kontur
    prime::TerrainSettings tTerrain = mXMap->getTerrainSettings();
    tTerrain.mShadingStrength = 0.8;
    tTerrain.mVfrContourLines = true;
    mXMap->setTerrainSettings(tTerrain);
}

void TextureHost::disable()
{
    // Siralama: once haritalar (ayarlari yazilir), sonra yonetici, en son pencere
    if (mWindow && XPLMHasKeyboardFocus(mWindow))
    {
        XPLMTakeKeyboardFocus(nullptr);
    }
    if (mManager)
    {
        if (mXMap)
        {
            mManager->removeXMap(mXMap);
            mXMap = nullptr;
        }
        mManager->shutdown();
        prime::XMapManagerFactory::destroyXMapManager(mManager);
        mManager = nullptr;
    }
    if (mWindow)
    {
        XPLMDestroyWindow(mWindow);
        mWindow = nullptr;
    }
}

void TextureHost::updateMapRect()
{
    int tLeft = 0;
    int tTop = 0;
    int tRight = 0;
    int tBottom = 0;
    XPLMGetWindowGeometry(mWindow, &tLeft, &tTop, &tRight, &tBottom);
    mMapLeft = tLeft + kMargin;
    mMapBottom = tBottom + kMargin;
    mMapWidth = (tRight - tLeft) - 2 * kMargin;
    mMapHeight = (tTop - tBottom) - 2 * kMargin;
}

void TextureHost::draw()
{
    if (!mXMap)
    {
        return;
    }
    // Pencere tasindi / boyutlandi: ayni kare icinde haritaya yeni boyut (ayni boyutta is yapilmaz)
    updateMapRect();
    mXMap->setTextureSize(mMapWidth, mMapHeight);
    syncKeyboardFocus(false);

    // Doku gerekiyorsa yeniden cizilir (degisiklik, girdi ya da max_fps); false: basacak doku yok
    if (!mXMap->renderTexture() || mXMap->getTextureId() == 0)
    {
        return;
    }
    XPLMSetGraphicsState(0, 1, 0, 0, 0, 0, 0);  // 1 doku birimi, saydamlik yok (harita opak)
    XPLMBindTexture2d(static_cast<int>(mXMap->getTextureId()), 0);
    glColor4f(1.0f, 1.0f, 1.0f, 1.0f);
    glBegin(GL_QUADS);  // doku: (0,0) sol-alt, (1,1) sag-ust
    glTexCoord2f(0.0f, 0.0f);
    glVertex2i(mMapLeft, mMapBottom);
    glTexCoord2f(1.0f, 0.0f);
    glVertex2i(mMapLeft + mMapWidth, mMapBottom);
    glTexCoord2f(1.0f, 1.0f);
    glVertex2i(mMapLeft + mMapWidth, mMapBottom + mMapHeight);
    glTexCoord2f(0.0f, 1.0f);
    glVertex2i(mMapLeft, mMapBottom + mMapHeight);
    glEnd();
}

int TextureHost::forwardClick(int pX, int pY, XPLMMouseStatus pStatus, prime::MouseButton pButton, bool* pPressed)
{
    // Basma haritanin icinde baslamissa surukleme ve birakma (disari tassa da) haritaya gider
    const int tX = pX - mMapLeft;  // doku koordinati: orijin sol-alt, birim boxel
    const int tY = pY - mMapBottom;
    if (pStatus == xplm_MouseDown)
    {
        *pPressed = mXMap && tX >= 0 && tY >= 0 && tX < mMapWidth && tY < mMapHeight;
    }
    if (!*pPressed)
    {
        return 1;
    }
    prime::MouseAction tAction = prime::MouseAction::Down;
    if (pStatus == xplm_MouseDrag)
    {
        tAction = prime::MouseAction::Drag;
    }
    else if (pStatus == xplm_MouseUp)
    {
        tAction = prime::MouseAction::Up;
        *pPressed = false;
    }
    mXMap->injectMouse(tX, tY, tAction, pButton);
    syncKeyboardFocus(tAction == prime::MouseAction::Down);  // "Go to airport" kutusuna tiklandiysa yaz
    return 1;
}

void TextureHost::syncKeyboardFocus(bool pTake)
{
    // Klavye odagini sadece harita istediginde (arama kutusu) ve haritaya tiklaninca al; istemeyince birak
    const bool tWants = mXMap && mXMap->wantsKeyboard();
    const bool tHas = XPLMHasKeyboardFocus(mWindow) != 0;
    if (pTake && tWants && !tHas)
    {
        XPLMTakeKeyboardFocus(mWindow);
    }
    else if (!tWants && tHas)
    {
        XPLMTakeKeyboardFocus(nullptr);
    }
}

9.1 Görünürlük

  • Üst öğeyi kapatmak alt öğeleri gizler; alt öğelerin kendi durumu korunur.
  • Kapalı katmanın bir alt katmanını açmak sadece o alt katmanı açar (katman Mixed).
  • Son alt katman kapanınca katman da kapanır; bütün alt katmanları kapalı bir katman açılınca hepsi açılır.
  • Grup açmak o modda varsayılan açık katmanları açar. Durum mod başına ve harita başına saklanır; mod değişince o modun durumu gelir.

9.2 Zoom aralığı

Her katmanın yerleşik bir görünme eşiği vardır (bölüm 10). setLayerZoomRange bu eşiğin üstüne bir pencere koyar: katman ancak hem yerleşik eşiği hem verilen aralığı geçince çizilir. Kutu durumu (isLayerVisible) değişmez.

map->setLayerZoomRange(prime::XMapLayer::AirwaysGroup, 8.0, 99.0);  // hava yollari ancak zoom 8'den yakinda
map->setLayerZoomRange(prime::XMapLayer::Fixes, 10.5, 99.0);        // fix'ler 10.5'ten itibaren
map->setLayerZoomRange(prime::XMapLayer::Terrain, 0.0, 12.0);       // zemin 12'den yakinda cizilmez
map->setLayerZoomRange(prime::XMapLayer::RoadsLocal, 13.0, 99.0);   // alt katman: yerel yollar 13+
map->clearLayerZoomRange(prime::XMapLayer::Fixes);                  // siniri kaldir

Her yöneticinin iki klasörü vardır: veri klasörü (setDataDirectory; içinde merkez prime_map.json ve harita başına maps/<ad>/ ayarları) ve karo önbellek klasörü (setCacheDirectory; verilmezse <veri>/cache/). Kural: ayarlar her zaman veri klasörüne bağlıdır, karo önbelleği ise ayrı seçilebilir. Aynı süreçte ikinci bir yönetici aynı veri klasörüne çözülürse initialize tek satır WARNING yazar; yalnızca önbellek klasörü ortaksa tek satır bilgi yazar (yazımlar atomiktir, paylaşım güvenlidir).

a) Tek yönetici, n harita: ayarlar ayrı, önbellek ortak (önerilen)

prime::XMapManager* mgr = prime::XMapManagerFactory::createXMapManager();
mgr->setDataDirectory("C:/X-Plane/prime-xmap");   // hepsi icin tek veri klasoru (isteden)
mgr->initialize();
prime::XMap* a = mgr->addXMap();  a->setName("kaptan");   a->initialize();
prime::XMap* b = mgr->addXMap();  b->setName("plan");     b->initialize();
&lt;veri&gt;/prime_map.json      merkez: onbellek butceleri
&lt;veri&gt;/maps/kaptan/        harita a ayarlari (ayri)
&lt;veri&gt;/maps/uydu/          harita b ayarlari (ayri)
&lt;veri&gt;/cache/              ortak karo onbellegi

Haritalar arası karo ve veri paylaşımı anlıktır (tek yönetici, tek işçi). Dikkat: yönetici içinde harita adları eşsiz olmalıdır; aynı ad ikinci haritaya verilmez.

b) İki host eklentisi: ayarlar izole, karolar ortak

// host A (veri klasoru kendine ozel):
mgr->setDataDirectory("C:/X-Plane/pluginA/prime-xmap");
mgr->setCacheDirectory("C:/X-Plane/prime-cache");   // ikisi de ayniyi verir
mgr->initialize();

// host B:
mgr->setDataDirectory("C:/X-Plane/pluginB/prime");  // farkli
mgr->setCacheDirectory("C:/X-Plane/prime-cache");   // ayni
mgr->initialize();
&lt;veri-A&gt;/prime_map.json + maps/&lt;ad&gt;/   ayarlar izole
&lt;veri-B&gt;/prime_map.json + maps/&lt;ad&gt;/   ayarlar izole
&lt;ortak&gt;/terrain/...                    karo onbellegi paylasilir

Güvenlik notu: önbellek yazımları geçici dosya + yeniden adlandırmayla atomiktir; okuma tarafında anahtar doğrulanır, yarım yazılmış dosya asla görünmez; CacheTrim yarışması kendini onarır (silinen karo yeniden üretilir). Paylaşım bilinçli kurulumsa initialize bunu tek satır bilgi olarak yazar.

c) Tam izolasyon

mgrA->setDataDirectory("C:/X-Plane/pluginA/prime-xmap");   // onbellek kendiliginden
mgrB->setDataDirectory("C:/X-Plane/pluginB/prime-xmap");   // &lt;veri&gt;/cache/ olur

Ayarlar da karolar da ayrıdır; iki host hiçbir diske dokunmaz. Bellek / doku bütçeleri yönetici başına ayrı tutulur (paylaşım yoktur).

d) Hiçbir klasör verilmezse (varsayılan)

// ikinci yonetici de veri klasorune dokunmuyorsa:
// &lt;veri&gt; = %LOCALAPPDATA%/prime/prime-xmap , onbellek = &lt;veri&gt;/cache

Risk: iki yöneticinin ayarları çakışır — aynı prime_map.json (farklı değer yazan ezer) ve aynı adlı maps/<ad>/ klasörleri. initialize bunu tek satır WARNING ile bildirir: give each manager its own data directory (setDataDirectory) or use distinct map names. Önbellek klasörü de aynı olduğundan ikinci yönetici DSF taramadan önbellekten okur.

e) Ayar kopyası (klasörlerden bağımsız)

mapB->importSettings(mapA->exportSettings());               // gorunum, mod, katmanlar,
                                                            // zoom araliklari, renkler,
                                                            // kaynaklar + pencere/view bolumleri
mapB->importTerrainSettings(mapA->exportTerrainSettings()); // zemin
mapB->importDrawings(mapA->exportDrawings());               // cizimler

exportSettings pencere (başlık, yer, stil) ve görünüm (merkez, zoom, takip) bölümlerini de taşır: kopya, kaynağıyla aynı yerde ve aynı görünümde açılır. Bunu istemiyorsanız aktarım sonrası setGeometry / setCenter / setZoom ile ezin.

f) Canlı senkron (kütüphanede yoktur)

// host tarafinda iki yol:
// 1) her setX cagrisini iki haritaya da yapmak
// 2) revizyonlari izleyip fark degistiyse aktarmak
if (mapA->getSettingsRevision() != tLast) { tLast = mapA->getSettingsRevision(); mapB->importSettings(mapA->exportSettings()); }
if (mapA->getDrawingsRevision() != tLastDrw) { tLastDrw = mapA->getDrawingsRevision(); mapB->importDrawings(mapA->exportDrawings()); }

Sınırlar: importSettings pencere / görünümü de kopyalar (yukarıdaki e maddesi); importDrawings çizimleri bütün olarak değiştirir (artımlı değil); geri yansıma (mapB değişince mapA'ya yazmak) sonsuz döngüye açıktır — host bunu engellemeli. Dizin paylaşımı canlı senkron sağlamaz: ayarlar initialize'da bir kez okunur.

15. Sınırlar ve bilinen hatalar

  • Katman zoom aralığı yerleşik eşiği sadece daraltır; renkler modlar arası ortak; 14 katman dışında renk, hiçbir katmanda kalınlık / boy ayarı yok (bölüm 9).
  • Log öneki süreç genelinde tektir: aynı süreçte birden çok host varsa son setLogPrefix bütün satırlarda görünür.
  • Aynı süreçte ikinci yönetici aynı veri klasörüne çözülürse initialize tek satır WARNING, yalnızca önbellek klasörü ortaksa tek satır bilgi yazar (bölüm 14b).
  • Aynı süreçteki bütün host'lar aynı prime_map.dll'yi kullanır (Windows aynı adlı DLL'i bir kez yükler): sürümler aynı olmalı.
  • Her yöneticinin bir zemin işçisi vardır; birbirinden uzak yerlere bakan çok sayıda harita aynı işçiyi paylaşır. Bölge ön önbelleği aynı anda tek alan içindir.
  • Texture: host penceresi pop-out edilmişse (ayrı GL bağlamı) çizilmez. setXPlaneFont(true) ile etiketler dokuda yanlış yere düşebilir.
  • LEGACY Embedded stilde harita ayrı bir penceredir: host penceresinin önünde tutmak host'un işidir ve tıklama / sıralama sorunları çıkar. LEGACY stiller ileride kaldırılacaktır.
  • Genel başlıklar (XMap.h) kütüphanenin iç başlıklarını da içerir; C4251 uyarısı yalnızca bu sınıflar için kapatılmıştır. Host ile kütüphane aynı MSVC ve /MD ile derlenmelidir.
  • Bina / 3B nesne yok; 180. boylam civarı kısmen; yazılar ASCII; ILS yönü gerçek (true).
