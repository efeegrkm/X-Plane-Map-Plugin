Prime Map API 0.23 — Referans

Herhangi bir X-Plane 11 eklentisine gömülebilen harita kütüphanesi · 2026-11-12 · harita fabrikası, bağımsız çoklu harita, harita başına ayar dosyaları, ortak önbellek

1. Tanım

Prime Map API, X-Plane 11 eklentilerinin kendi arayüzlerine katmanlı bir hareketli harita yerleştirmesini sağlayan bir C++ kütüphanesidir (SHARED DLL: prime_map.dll). Harita, verisini sadece X-Plane'den alır: kurulu DSF sahneleri (zemin, su, yollar), apt.dat (havalimanları), nav veritabanı, earth_awy.dat (hava yolları), dataref'ler (uçak) ve FMS (rota). Her harita kendi XPLM penceresinde, kütüphanenin flight loop'uyla çizilir; host eklenti harita nesnesini fabrikadan alır, ayarlar, açar ve bütün davranışı API fonksiyonlarıyla yönetir.

ÖzellikDeğer
PlatformX-Plane 11, Windows x64, SDK 3.0 (XPLM301). Host her zaman bir X-Plane eklentisidir.
Dil, derleyiciC++20, MSVC 2022, /MD CRT (host da /MD olmak zorunda)
Ad alanı / başlıkprime / tek başlık PrimeMap.h (#include <prime_map_api/PrimeMap.h>; sadece standart C++ tipleri)

Ortak olanVeri ve önbellek: nav, havalimanları, hava yolları, zemin disk önbelleği, bellekteki karolar, video belleğindeki dokular. Bir haritanın yüklediği karo diğerine de yarar. Sınırlar açık harita sayısıyla büyür (bölüm 9).
ThreadBütün fonksiyonlar X-Plane ana thread'inden çağrılır
Hata modeliİstisna yok. Geçersiz değer: işlem yapılmaz, Log'a tek satır WARNING, dönüş false / boş.

2. Hızlı başlangıç

Adım 1 — Derlemeye bağlayın

prime_map_api klasörünü eklenti projenizin yanına alın (kardeş klasör). Gereksinimler: C++20, MSVC 2022 (/MD), X-Plane SDK 3.0 (C:\workspace\cots\X-Plane-SDK; yoksa kardeş cots klasörü ya da -DCOTS_DIR=...).

set(PRIME_MAP_DIR "${CMAKE_SOURCE_DIR}/../prime_map_api" CACHE PATH "prime_map_api klasoru")
add_subdirectory(${PRIME_MAP_DIR} prime_map_build)
target_link_libraries(host PRIVATE prime_map          # include yolu ve /MD transitif gelir
                      ${XPSDK}/Libraries/Win/XPLM_64.lib opengl32)
target_compile_definitions(host PRIVATE XPLM200=1 XPLM210=1 XPLM300=1 XPLM301=1 IBM=1 APL=0 LIN=0)
add_custom_command(TARGET host POST_BUILD             # prime_map.dll win.xpl'nin yanina
    COMMAND ${CMAKE_COMMAND} -E copy_if_different $<TARGET_FILE:prime_map> $<TARGET_FILE_DIR:host>)

Adım 2 — Fabrikadan harita alın, ayarlayın, açın

#include <prime_map_api/PrimeMap.h>

std::unique_ptr<prime::Map> gMap;

PLUGIN_API int XPluginEnable()
{
    prime::MapLibrary& tLib = prime::MapLibrary::Get();
    prime::InitConfig tInit;
    tInit.mLogPrefix = "[my-host]";
    tLib.Init(tInit);                                 // veri arka planda yuklenmeye baslar

    gMap = tLib.CreateMap();                          // FABRIKA: nesne var, pencere henuz yok
    gMap->SetName("ios_left");                        // ayar klasoru: maps/ios_left/
    gMap->SetStyle(prime::WindowStyle::Embedded);     // cercevesiz; yeri host belirler
    gMap->SetGeometry({100, 800, 900, 600});          // sol, ust, genislik, yukseklik (boxel)
    gMap->SetMode(prime::MapMode::Vfr);
    gMap->SetCenter(47.45, -122.30);
    gMap->SetZoom(10.0);
    gMap->SetZoomLimits(6.0, 15.0);                   // bu harita 6'dan uzaga, 15'ten yakina gitmez
    gMap->SetLayerVisible(prime::MapLayer::Roads, false);
    gMap->SetMouseInput(true);
    gMap->Open();                                     // pencere bu ayarlarla acilir
    return 1;
}

PLUGIN_API void XPluginDisable()
{
    gMap.reset();                                     // ayarlar yazilir, pencere kapanir
    prime::MapLibrary::Get().Shutdown();
}

3.2 Dosyalar ve klasörler

Hepsi veri klasörünün altındadır. Veri klasörü: InitConfig::mDataDirectory; boşsa host eklentisinin klasörü (<X-Plane>/Resources/plugins/<host>/).

<veri klasoru>/
  prime_map.ini                    merkezi ayarlar (butun haritalar; bolum 9)
  maps/
    ios_left/                      SetName("ios_left") verilen harita
      map_settings.ini             pencere, gorunum, mod, katmanlar, zoom sinirlari, kaynaklar (bolum 8)
      map_drawings.txt             kullanici cizimleri
      terrain_colors.ini           bu haritanin zemin renkleri / ayarlari
    map_2/                         ad verilmeyen harita: "map_<kimlik>"
      ...
  cache/                           ORTAK onbellek (silinebilir)
    terrain/                       *.terrain *.elevation *.vectors *.nobase, xplane_palette.txt
    airports/                      airport_index.bin
KonuKural
Harita adıSetName ile verilir. Klasör adında harf, rakam, - _ . dışındaki karakterler _ olur. Ad verilmezse klasör map_<kimlik> (kimlik = oluşturulma sırası, 1'den başlar; haritalar hep aynı sırayla oluşturuluyorsa klasör de aynı kalır). Kalıcı ayar isteyen host ad vermelidir.
Aynı adİki canlı harita aynı klasörü kullanamaz: ikinci SetName false döner.
Ne zaman okunurOpen() sırasında (sadece Persistence::LoadAndSave).
Ne zaman yazılırİlk Open()'da (dosyalar oluşsun); bir ayar değişince ([maps] autosave, en sık autosave_seconds arayla); Close(), harita bırakılırken, Shutdown; Map::SaveSettings().
ÖnbellekTek yerde, bütün haritalar için ortak. InitConfig::mCacheDirectory ile başka yere alınabilir.
Birden çok hostAynı X-Plane sürecinde kütüphane tektir: ilk Init eden host'un klasörleri geçerlidir (diğerlerinin InitConfig'i yok sayılır, Log'a yazılır). Hostların haritaları aynı maps/ altında durur: adları farklı seçin.

Embedded / Standalone farkı: [window] (yer, boyut, görünürlük) sadece Standalone haritada dosyadan geri yüklenir (kullanıcı pencereyi taşır). Embedded haritanın yerini ve görünürlüğünü her zaman host belirler.

7. Katmanlar

enum class MapLayer grupları, katmanları ve alt katmanları tek listede tutar. Ağaç: TopLevelLayers(), ParentOf(), ChildrenOf(), KindOf(); adlar: LayerName(), LayerKey() (ayar anahtarı), LayerFromKey(); varsayılan: IsLayerDefaultVisible(layer, mode).

GrupKatman → alt katmanlar
MapGroupTerrain → TerrainForests, TerrainBuiltUp; Roads → RoadsMotorways, RoadsPrimary, RoadsSecondary, RoadsLocal, RoadsRailways, RoadsPowerLines; Grid
AirportsGroupAirportSymbols; Runways → RunwaysPaved, RunwaysUnpaved, RunwaysWater, RunwaysOverruns, RunwaysMarkings, RunwaysNumbers; Surfaces → SurfacesPavement, SurfacesPavementEdges, SurfacesBoundary, SurfacesMarkings; Objects → ObjectsLighting, ObjectsHelipads, ObjectsBeacons, ObjectsWindsocks, ObjectsGates, ObjectsTieDowns, ObjectsHangars, ObjectsOtherStarts, ObjectsStartNames, ObjectsApproachLights, ObjectsSigns; TaxiRoutes
NavaidsGroupVor, Ndb, Ils, Fixes
AirwaysGroupAirwaysLow, AirwaysHigh
FlightGroupAircraft, FmsRoute, FlightTrack
(grupsuz)Drawings → DrawingsPoints, DrawingsRoutes, DrawingsRegions, DrawingsLabels

Görünürlük kuralları

  • Üst öğeyi kapatmak alt öğeleri gizler; alt öğelerin kendi durumu korunur.
  • Kapalı katmanın bir alt katmanını açmak sadece o alt katmanı açar (katman Mixed).
  • Son alt katman kapanınca katman da kapanır; bütün alt katmanları kapalı bir katman açılınca hepsi açılır.
  • Grup açmak sadece o modda varsayılan açık katmanları açar. Durum mod başına ve harita başına saklanır.

Zoom aralığı ("şu uzaklıktan itibaren görünsün")

Her katmanın yerleşik eşikleri vardır (örnek: pistler zoom 11+, VOR 5+, NDB 7+, fix 9+, hava yolları 6.5+, yollar 7.5+). SetLayerZoomRange bunları daraltır (erkene alamaz); kutu durumu (IsLayerVisible) değişmez.

map->SetLayerZoomRange(prime::MapLayer::AirwaysGroup, 8.0, 99.0);   // hava yollari ancak zoom 8'den yakinda
map->SetLayerZoomRange(prime::MapLayer::Fixes, 10.5, 99.0);         // fix'ler 10.5'ten itibaren
map->SetLayerZoomRange(prime::MapLayer::Terrain, 0.0, 12.0);        // zemin 12'den yakinda cizilmez
map->SetLayerZoomRange(prime::MapLayer::RoadsLocal, 13.0, 99.0);    // alt katman: yerel yollar 13+
map->ClearLayerZoomRange(prime::MapLayer::Fixes);                   // siniri kaldir

Harita kapanınca sınır geri iner; fazlası işçinin ilk boş anında silinir. Geçerli değerler: GetStatus().mTerrainCacheLimitMb, mTextureLimitMb. Çalışırken değiştirme:

prime::LibrarySettings s = prime::MapLibrary::Get().GetSettings();
s.mTerrainCacheMb = 4096;              // harita basina taban 4 GB
s.mCacheGrowthPercentPerMap = 10;
prime::MapLibrary::Get().SetSettings(s);   // hemen uygulanir + prime_map.ini'ye yazilir

Dosya ile InitConfig çakışırsa dosya kazanır (kullanıcının ayarı); InitConfig sadece dosyada olmayan anahtarların ilk değerini verir.

11. Tarifler

Host penceresine gömülü harita, host düğmeleriyle

map->SetStyle(prime::WindowStyle::Embedded);
map->SetUiVisible(false);  map->SetMouseInput(false);    // butun kontrol host'ta
map->Open();
// host'un dugmeleri:           map->ZoomIn();  map->PanLeft();  map->NextMode();
// host penceresi tasininca:    map->SetGeometry({x, y, w, h});

Aynı uçuşun iki görünümü

overview->SetMode(prime::MapMode::IfrHigh);  overview->SetZoom(6);   overview->SetFollowAircraft(true);
detail->SetMode(prime::MapMode::Scenery);    detail->SetZoom(14);    detail->SetFollowAircraft(true);
detail->ShowOnlyLayers({prime::MapLayer::Terrain, prime::MapLayer::Runways, prime::MapLayer::Surfaces,
                        prime::MapLayer::Aircraft});

Haritaya kimlikle erişim

const int id = map->GetId();
if (prime::Map* m = prime::MapLibrary::Get().FindMap(id))        m->SetMode(prime::MapMode::Dark);
if (prime::Map* m = prime::MapLibrary::Get().FindMap("overview")) m->SetVisible(false);
for (prime::Map* m : prime::MapLibrary::Get().GetMaps())          m->SetMaxRenderFps(10);

Bir haritanın ayarını diğerine kopyalama

mapB->ImportSettings(mapA->ExportSettings());                 // gorunum, mod, katmanlar, zoom araliklari
mapB->ImportTerrainSettings(mapA->ExportTerrainSettings());   // zemin
mapB->ImportDrawings(mapA->ExportDrawings());                 // cizimler

Ayarları her açılışta koddan (dosya sadece kayıt)

map->SetPersistence(prime::Persistence::SaveOnly);

13. Sınırlar

  • Zemin işçisi tektir: birbirinden uzak yerlere bakan çok sayıda harita aynı işçiyi paylaşır (istekler her haritanın kendi merkezine göre sıralanır).
  • Bölge ön önbelleği (Precache...) aynı anda tek alan içindir (son çağrı geçerli).
  • 32'den fazla haritada doku işaretleri paylaşılır (sonuç yalnızca gereksiz yeniden istek).
  • SetXPlaneFont(true) iken harita resmi önbelleği kullanılmaz.
  • 180. boylam civarı kısmen ele alınır; yazılar ASCII.
