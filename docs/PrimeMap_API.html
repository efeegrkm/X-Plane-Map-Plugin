Prime Map API 1.0

X-Plane 11 haritasını başka bir X-Plane eklentisine gömmek için C++ statik kütüphane · prime-map-plugin 0.20 · 2026-11-08

1. Genel bakış

Prime Map, X-Plane'in kendi verisinden (kurulu DSF sahneleri, apt.dat, nav veritabanı, earth_awy.dat, dataref'ler, FMS) çizilen katmanlı bir haritadır. Prime Map API bu haritayı başka bir X-Plane eklentisinin (ilk hedef: GNS 430W eklentisi) içine gömer: harita UI'sız, saf bir harita olarak açılır ve her şey fonksiyonlarla yönetilir. Host bu fonksiyonları kendi düğmelerine bağlar.

  • Tek harita: eklenti (DLL) başına bir harita. İkinci Map::Open nullptr döner.
  • Kendi penceresi: harita kendi XPLM penceresinde, kendi flight loop'uyla kendisi çizer. Host sadece açar, yerini/boyutunu söyler.
  • Saf harita / UI'lı harita: SetUiVisible(true) ile bugünkü eklentinin üst şeridi, katman paneli, mod paneli, çizim paleti, havalimanı arama, durum şeridi ve tooltip kutusu haritanın içinde açılır.
  • Prime Map Plugin'in kendisi de haritaya sadece bu API üzerinden erişir (src/plugin/PluginMain.cpp). Bu sayede eklentide yapılabilen her şey API'de de vardır.
Ekran görüntüleri bu sürümde yok. Saf/UI'lı karşılaştırmalar, beş mod ve fare/UI kombinasyonları X-Plane'de denendikten sonra eklenecek (görüntüleri kullanıcı X-Plane'den alacak).

2. Hızlı başlangıç

Paket

prime_map_sdk/
  include/PrimeMap.h            tek genel başlık (sadece standart C++)
  lib/prime_map_MT.lib          /MT  Release      lib/prime_map_MTd.lib  /MTd Debug

Paketi üretmek (proje kökünden; iki CRT için iki derleme klasörü):

cmake -S . -B b_mt -G Ninja -DCMAKE_BUILD_TYPE=Release -DPRIME_MAP_DYNAMIC_CRT=OFF
cmake --build b_mt --target prime_map
cmake --install b_mt --prefix prime_map_sdk
(aynısı -DPRIME_MAP_DYNAMIC_CRT=ON ve Debug için)

Host'un CMake'i

target_include_directories(gns PRIVATE ${PRIME_MAP_SDK}/include)
target_link_libraries(gns PRIVATE
    ${PRIME_MAP_SDK}/lib/prime_map_MT$<$<CONFIG:Debug>:d>.lib   # host /MT ise
    ${XPSDK}/Libraries/Win/XPLM_64.lib opengl32)

LZMA (7z açıcı) kütüphanenin içindedir; ek dosya, DLL ya da kurulum gerekmez. Yazı tipi X-Plane'in kendi Resources/fonts/DejaVuSans.ttf dosyasından okunur (her X-Plane kurulumunda var), varsayılan palet koddadır. Host'un CRT'si ile kütüphanenin CRT'si aynı olmalı (MT/MD, Debug/Release).

En kısa örnek

#include "PrimeMap.h"
std::unique_ptr<PrimeMap::Map> gMap;

PLUGIN_API int XPluginEnable()
{
    PrimeMap::Init({});                                  // veri arka planda yüklenmeye başlar
    PrimeMap::OpenConfig tOpen;
    tOpen.mGeometry = {100, 700, 480, 320};              // sol, üst, genişlik, yükseklik (boxel)
    tOpen.mStyle = PrimeMap::WindowStyle::Embedded;
    gMap = PrimeMap::Map::Open(tOpen);
    gMap->GoToAirport("KSEA");
    return 1;
}

PLUGIN_API void XPluginDisable()
{
    gMap.reset();             // önce harita
    PrimeMap::Shutdown();     // sonra kütüphane
}

3. Kavramlar

Yaşam döngüsü ve thread

Init (XPluginEnable) → Map::Open → ... → Map yok edilir → Shutdown (XPluginDisable). Bütün fonksiyonlar X-Plane ana thread'inden çağrılır (XPLM callback'leri, flight loop). Kütüphanenin kendi arka plan thread'leri vardır ama dışarıya açılmaz. Shutdown harita açıkken çağrılırsa pencereyi kendisi kapatır ve log'a uyarı yazar; Map nesnesi bundan sonra hiçbir şey yapmaz.

Koordinatlar ve birimler

Ekran koordinatları X-Plane'in global ekran birimi (boxel)dir: XPLMGetWindowGeometry, XPLMGetScreenBoundsGlobal ve fare callback'leriyle aynı. x sağa, y yukarı artar. Geometry sol-üst köşe + genişlik/yükseklik verir:

  (mLeft, mTop) ●──────────── mWidth ────────────┐
                │                                  │  XPLM karşılığı:
                │            harita                │  left   = mLeft
           mHeight                                 │  top    = mTop
                │                                  │  right  = mLeft + mWidth
                └──────────────────────────────────┘  bottom = mTop - mHeight

Boxel, X-Plane'in UI ölçeği %100 iken pikselle aynıdır; ölçek %150 iken bir boxel 1,5 pikseldir. API her yerde boxel kullanır, piksel dönüşümünü kütüphane kendisi yapar (ScreenToGeo, PanBy, SetGeometry hep boxel). Enlem/boylam derece; zoom Web Mercator seviyesi (3 … 16,5; bir tekerlek tıkı 0,5).

4. API referansı

Ad alanı PrimeMap. Hata modeli: istisna yok; geçersiz değer → bir şey yapılmaz, log'a tek satır uyarı, dönüş false / boş. Değeri kütüphane kontrol eder (örnek zoom kırpılır).

4.7 Sorgu

QueryAt(lat, lon), QueryAtScreen(x, y) → std::vector<MapObject{mLayer, mText}>: imlecin altında bir şey bulunan her görünen katman, en üstteki önce; metin tooltip'teki metnin aynısı. Son çizilen kareye göre çalışır (pencere görünür olmalı).

4.8 Ayarlar

ExportSettings() / ImportSettings(text)INI metni: [view] mode, center_lat/lon, zoom, follow_aircraft; [tools] (çizim paleti); [layers.scenery|vfr|ifr_low|ifr_high|dark]. Anahtarlar 0.19 map_settings.ini ile aynı: eski dosya olduğu gibi verilebilir (diğer bölümler yok sayılır).
GetTerrainSettings / SetTerrainSettings, ExportTerrainSettings / ImportTerrainSettingsterrain_colors.ini'nin bütün anahtarları (palet kaynağı, sınıf renkleri, gölge, blend, warp, closeup, relief, water, vfr bantları). Zemin işçisi ilk karede başlar: Open'dan hemen sonra, ilk kareden önce verilen ayar tam etkilidir; sonra verilen bir sonraki X-Plane açılışında etkili olur.

4.9 Ön önbellek ve teşhis

PrecacheVisibleArea(), PrecacheArea(GeoBounds): alandaki kurulu DSF karolarını diske hazırlar; alan önbellek sınırının %80'inden büyükse ya da sahne yoksa başlamaz (false, nedeni durum metninde). CancelPrecache(). SetDiagnostics / IsDiagnosticsOn: Log.txt'ye her 2 s'de DIAG satırı, durum şeridinde FPS/çizim süresi.

5. Katmanlar

Gruplar, katmanlar ve alt katmanlar tek düz MapLayer enum'u; sıra katman paneliyle aynı. Yardımcılar: ParentOf (en üst öğede nullopt), ChildrenOf, TopLevelLayers, KindOf, LayerName, LayerKey, LayerFromKey, IsLayerDefaultVisible(layer, mode). Haritada: SetLayerVisible, IsLayerVisible, ToggleLayer (panel kutusuna tıklamanın aynısı), SetLayersVisible, ShowOnlyLayers, ResetLayersToDefaults ("Defaults"), GetLayerState (Off/On/Mixed).

Kurallar (panel ve API aynı kodu çalıştırır: src/engine/LayerTable.cpp)

  • Üst öğeyi kapatmak alt öğeleri gizler (alt öğelerin kendi durumu saklanır).
  • Kapalı bir katmanın alt katmanını açmak sadece o alt katmanı açar; katman "yarım" (Mixed) görünür.
  • Son alt katman kapanınca katman da kapanır; bütün alt katmanları kapalı bir katman açılınca hepsi açılır.
  • Grubu açmak sadece o modda varsayılan açık katmanları açar (Taxi routes gibi varsayılan kapalılar tek tek açılır). ToggleLayer(grup): varsayılan açıklardan biri kapalıysa onları açar, değilse gruptaki her şeyi kapatır.
  • ShowOnlyLayers: her katman kapanır; verilen katman bütün alt katmanlarıyla, verilen alt katman tek başına, verilen grup varsayılanlarıyla açılır.
tMap->SetLayerVisible(PrimeMap::MapLayer::AirwaysGroup, false);
tMap->SetLayerVisible(PrimeMap::MapLayer::RunwaysWater, true);   // Runways kapalıysa sadece su pistleri
tMap->ShowOnlyLayers({PrimeMap::MapLayer::Terrain, PrimeMap::MapLayer::Runways, PrimeMap::MapLayer::Vor});

7. Örnek eklenti: tools/map_api_demo

XPluginEnable'da Init, kendi çerçeveli XPLM penceresi ("host window") ve onun iç alanına Embedded harita (UI ve fare kapalı, VFR). Flight loop haritayı host penceresinin iç alanına yerleştirir (SetGeometry); host penceresi tıklanınca BringToFront. Komutlar (Plugins > Map API Demo menüsü ve ozdev/map_demo/*): zoom in/out, pan, next mode, IFR Low, Go to KSEA, Fit Seattle area, Follow aircraft, Toggle airways group, Show only basics, Toggle map UI, Toggle map mouse input.

Derleme -DMAP_API_DEMO=ON (varsayılan); X-Plane'e kurmak için -DMAP_DEPLOY_DEMO=ON (Resources/plugins/map_api_demo/64/win.xpl). Demo kendi veri kopyasını yükler; Prime Map Plugin ile birlikte açıkken bellek ve açılış süresi iki katına çıkar.

8. Bilinen sınırlar

  • Tek harita; X-Plane dışı kullanım yok; 3D kokpit paneline çizim yok.
  • Aynı X-Plane'de iki eklenti kütüphaneyi kullanırsa veriyi ayrı ayrı yükler. Aynı önbellek klasörünü paylaşmaları önerilmez (önbellek dosyaları henüz geçici-dosya + yeniden adlandırma ile yazılmıyor; ayar dosyası yazımı öyle).
  • Haritanın kendi UI'ı (src/ui) hâlâ motorun içinden çizilir; düğme eylemleri ve katman kuralları API ile aynı koddan geçer ama UI kodunun derleme düzeyinde sadece PrimeMap.h'i görmesi henüz zorlanmıyor.
  • GNS'e özel özellikler (NM menzil, harita döndürme, declutter seviyeleri, imleç) sonraki sürüm.
  • QueryAt sadece tooltip metnini verir (ayrı kimlik alanı yok).
