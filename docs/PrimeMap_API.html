Prime Map API 1.0 — Referans

Herhangi bir X-Plane 11 eklentisine gömülebilen harita kütüphanesi · 2026-11-08

1. Tanım

Prime Map API, X-Plane 11 eklentilerinin kendi arayüzlerine katmanlı bir hareketli harita yerleştirmesini sağlayan bir C++ statik kütüphanedir. Harita, verisini sadece X-Plane'den alır: kurulu DSF sahneleri (zemin, su, yollar), apt.dat (havalimanları), nav veritabanı, earth_awy.dat (hava yolları), dataref'ler (uçak) ve FMS (rota). Harita kendi XPLM penceresinde, kendi flight loop'uyla çizilir; host eklenti pencereyi açar, konumlandırır ve bütün davranışı API fonksiyonlarıyla yönetir. Haritanın yerleşik arayüzü (araç şeridi, katman paneli, mod paneli, çizim paleti, havalimanı arama, durum şeridi, tooltip) isteğe bağlıdır.

Host, PrimeMap.h'i include eder; kendi CRT'sine uyan .lib'i, XPLM_64.lib'i ve opengl32'yi bağlar. Başka dosya, DLL veya kurulum gerekmez (LZMA kütüphanenin içindedir; yazı tipi X-Plane'in Resources/fonts/DejaVuSans.ttf dosyasından okunur).

target_include_directories(host PRIVATE ${PRIME_MAP_SDK}/include)
target_link_libraries(host PRIVATE ${PRIME_MAP_SDK}/lib/prime_map_MT$<$<CONFIG:Debug>:d>.lib
                      ${XPSDK}/Libraries/Win/XPLM_64.lib opengl32)

Paketin üretilmesi: cmake -B b -DPRIME_MAP_DYNAMIC_CRT=OFF|ON -DCMAKE_BUILD_TYPE=Release|Debug, cmake --build b --target prime_map, cmake --install b --prefix prime_map_sdk.

3. Yaşam döngüsü

XPluginEnable :  PrimeMap::Init(config)                     veri yüklemesi başlar (arka planda)
                 auto map = PrimeMap::Map::Open(openConfig)  harita penceresi açılır
çalışırken    :  map->SetGeometry(...), map->ZoomIn(), map->SetMode(...) ...
XPluginDisable:  map.reset()                                pencere kapanır
                 PrimeMap::Shutdown()                       arka plan işleri durur

Veri yüklenirken harita hemen açılabilir; hazır olmayan katmanlar boş/kaba çizilir ve veri geldikçe tamamlanır (GetStatus). Zemin ayarı (ImportTerrainSettings/SetTerrainSettings), Open'dan hemen sonra ve ilk kareden önce verilirse tam etkilidir; sonradan verilen zemin ayarı bir sonraki X-Plane açılışında etkili olur.

8. Örnek: examples/map_api_test

Bütün API fonksiyonlarını çağıran ayrı bir X-Plane eklenti projesi; sadece paketi kullanır.

DosyaGörev
MapApiCalls.h/.cppHer API çağrısı ayrı bir metot (OpenMap, CloseMap, ZoomIn, SetLayerVisible ...). Eklentinin geri kalanı haritaya sadece bu sınıfla erişir
SelfTest.h/.cppX-Plane içinde bütün fonksiyonları sırayla çağırır, her kontrolü Log.txt'ye [map-api-test] PASS|FAIL olarak yazar
TestPluginMain.cppGiriş noktaları; Plugins > Map API Test menüsü aynı metotları elle çağırır (zoom, pan, mod, KSEA, katman, UI, fare, taşıma, boyut, göster/gizle)
#include "PrimeMap.h"

bool MapApiCalls::OpenMap(const PrimeMap::Geometry& pGeometry, PrimeMap::WindowStyle pStyle, bool pUi, bool pMouse)
{
    PrimeMap::OpenConfig tConfig;
    tConfig.mGeometry = pGeometry;
    tConfig.mStyle = pStyle;
    tConfig.mUiVisible = pUi;
    tConfig.mMouseInput = pMouse;
    mMap = PrimeMap::Map::Open(tConfig);
    return mMap != nullptr;
}
